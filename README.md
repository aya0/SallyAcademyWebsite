# Sally Academy

Sally Academy is a polished, responsive education website for a modern learning academy. It presents the academy's programs, teaching team, student stories, and leadership in a warm, welcoming interface designed for families and curious learners.

## Overview

The site combines a playful visual identity with clear calls to action and interactive content. It is built as a single-page React application and is ready to run locally with Vite.

### Highlights

- Responsive landing page for desktop, tablet, and mobile
- Hero section with enrollment and story actions
- Academy story and mission section
- Program cards for:
  - Private 1-on-1 sessions
  - Robotics and STEM labs
  - Full school-subject support
- Interactive program details modal
- Student stories carousel
- Interactive teacher cards and mentor details modal
- Leadership section with contact actions
- Enrollment form modal
- Video spotlight modal placeholder
- Custom Sally Academy favicon
- Site-wide Libre Caslon Condensed typography

## Tech Stack

- [React](https://react.dev/) 19
- [Vite](https://vite.dev/) 6
- JavaScript with JSX
- CSS
- Local TTF font asset

## Getting Started

### Prerequisites
